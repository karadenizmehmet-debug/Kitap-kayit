# Künye

Kitabın telif (künye) sayfasının fotoğrafından kitap kaydı oluşturan, okula ortak liste tutan ve Excel'e aktaran web uygulaması.

- Google ile giriş, yönetici onayı ve okul bazlı erişim
- Fotoğraftan alan okuma (ISBN, baskı yılı, kitap adı, baskı sayısı, yayınevi)
- Telefona uygulama olarak eklenebilir (PWA)
- Excel (.xlsx) dışa aktarma
